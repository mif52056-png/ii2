# JARVIS Mini

Небольшой русскоязычный помощник, который запускается прямо в браузере.

## Запуск
1. Распакуй архив.
2. Открой `index.html` в Chrome или Edge.
3. Разреши доступ к микрофону для голосового ввода.

Если браузер блокирует микрофон при открытии файла напрямую, запусти локальный сервер из этой папки:

```bash
python -m http.server 8000
```

Затем открой http://localhost:8000

## Команды
- `Привет`
- `Который час?`
- `Какая дата?`
- `Открой YouTube`
- `Открой Google`
- `Найди погода в Чикаго`
- `Запомни купить молоко`
- `Покажи заметки`
- `Помощь`

Заметки хранятся локально в браузере через localStorage. Это демонстрационный локальный помощник: он не подключён к нейросети и не управляет компьютером.
